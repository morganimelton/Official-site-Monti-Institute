# Monti Institute of Neuro Aesthetics Website

New development website for Monti Institute of Neuro Aesthetics in Reno, Nevada. This repository is separate from the current live website and should not be deployed over production until launch is approved.

## Local Preview

```sh
python3 -m http.server 5173
```

Open `http://localhost:5173/`.

## Verification

```sh
node scripts/check-site.mjs
```

Internal planning files:

- `CONTENT_AUDIT.md`
- `CLIENT_VERIFICATION.md`
- `REDIRECT_PLAN.md`

These files are not linked from the public website.
